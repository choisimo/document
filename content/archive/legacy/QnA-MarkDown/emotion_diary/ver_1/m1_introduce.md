# 감정 일기장 분석기 (Emotion Journal Analyzer) 프로젝트 계획서

감정 일기장 분석기는 사용자가 일상에서 느낀 감정을 기록하고, 텍스트 분석 결과를 자기 성찰의 보조 정보로 확인하는 서비스 기획안입니다.

프로젝트 목표는 일기 입력, 감정 분류, 기간별 기록 조회, 비의료적 자기 관리 안내를 하나의 흐름으로 연결하는 것입니다. 분석 결과는 진단이나 치료를 대신하지 않으며, 위기 상황에서는 AI 피드백보다 공식 긴급 지원 수단 안내를 우선합니다.

## 1. 서비스 개발 목적 및 개요

### 1.1 개발 배경 및 필요성

문서 작성 당시 배경 설명에는 세계보건기구(WHO)의 전 세계 정신 건강 관련 수치 약 13%가 인용되었습니다. 다만 이 문서에는 보고서명, 조사연도, 지표 정의가 없으므로 해당 수치는 출처를 확인하기 전까지 기획 배경 참고치로만 취급합니다.

 특히 코로나19 팬데믹 이후 불안, 우울, 스트레스 등의 정신 건강 문제가 더욱 심화되었습니다. 그러나 많은 사람들이 정신 건강 관리의 중요성을 인식하지 못하거나, 인식하더라도 적절한 도구가 부족한 실정입니다.

자기 성찰과 감정 기록은 정신 건강 관리의 효과적인 방법 중 하나로 알려져 있습니다.

 특히 일기 작성은 자신의 감정을 인지하고 처리하는 데 도움이 되는 것으로 여러 연구에서 입증되었습니다.
 
  그러나 단순히 일기를 쓰는 것을 넘어, 작성된 내용에서 감정 패턴을 분석하고 인사이트를 얻는 것은 쉽지 않은 과정입니다.

### 1.2 서비스 개요

감정 일기장 분석기는 사용자가 일기 형식으로 하루와 감정을 기록하면, AI 기술(ChatGPT API)을 활용하여 텍스트를 분석하는 흐름을 제안합니다. 범위 상태는 다음과 같습니다.

| 기능 | 범위 상태 | 완료 기준 |
| --- | --- | --- |
| 텍스트 기반 감정 분류 | 핵심 | 지원 감정 집합, 점수 범위, 실패 응답을 API 계약으로 정의하고 대표 입력 평가 통과 |
| 시간에 따른 감정 패턴 시각화 | 결정 필요 | 집계 기간, 결측값 처리, 최소 표본 수를 승인한 뒤 범위 확정 |
| 자기 관리 안내 | 핵심 | 의료 진단 표현을 차단하고 사용자가 분석을 수정·거절할 수 있는 경로 제공 |
| 전문가 연결 안내 | 선택 | 대상 지역의 검증된 연락처, 운영 시간, 갱신 책임자를 확보한 경우에만 노출 |

**처리 흐름(개념)**
[일기 입력] → [실시간 분석] → [맥락 인식] → [개인화 피드백] → [행동 유도]
