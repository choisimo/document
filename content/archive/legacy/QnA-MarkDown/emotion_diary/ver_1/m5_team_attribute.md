## 5. 개인 역할 분담

`n명`은 인원이 확정되지 않은 자리표시자입니다. 인원과 가용 시간이 정해지기 전에는 이 역할 목록을 일정 산정의 근거로 사용하지 않습니다. 한 사람이 여러 역할을 맡더라도 각 산출물에는 최종 승인자 한 명을 지정합니다.

### 5.1 프론트엔드 개발자 (n명)

- UI/UX 설계 및 구현
- 반응형 웹 인터페이스 개발
- 데이터 시각화 컴포넌트 구현
- 사용자 테스트 및 피드백 반영


### 5.2 백엔드 개발자 (n명)

- API 설계 및 개발
- 데이터베이스 스키마 설계
- 비즈니스 로직 구현
- 보안 및 인증 시스템 구축


### 5.3 AI 엔지니어 (n명)

- 감정 분석 알고리즘 개발
- ChatGPT, Gemini 등 AI API 통합 및 최적화
- 추천 시스템 개발
- 모델 성능 모니터링 및 개선


### 5.4 데이터 엔지니어 (n명)

- 데이터베이스 설계 및 관리
- 데이터 파이프라인 구축
- 데이터 마이그레이션
- 분석 및 보고서 생성


### 5.5 프로젝트 매니저 (n명)

- 요구사항 정의 및 관리
- 일정 및 리소스 계획
- 팀 조정 및 의사소통
- 품질 관리 및 리스크 관리

### 5.6 역할별 인계 기준

| 역할 | 책임 산출물 | 다음 역할로 넘기는 조건 |
| --- | --- | --- |
| 프론트엔드 | 사용자 흐름, 접근성 상태, API 사용 화면 | 오류·로딩·빈 상태를 포함한 계약 테스트 시나리오 합의 |
| 백엔드 | 버전이 명시된 API 스키마, 데이터 마이그레이션, 인증 정책 | API 문서와 구현의 차이가 없고 롤백 절차 기록 |
| AI | 평가 데이터 정의, 모델/프롬프트 버전, 안전 필터 결과 | 승인된 기준과 실패·저신뢰도 처리 경로 충족 |
| 데이터 | 스키마 소유권, 품질 규칙, 보존·삭제 작업 | 샘플 검증과 복구 시험 결과 기록 |
| 프로젝트 매니저 | 범위, 의존성, 의사결정·리스크 기록 | 담당자와 기한이 없는 항목이 릴리스 범위에서 제거됨 |
