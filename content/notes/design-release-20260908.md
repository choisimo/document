# 문서 허브 디자인 배포

`3f3b95d`의 원격 문서 본문을 기준으로 기존 preview.html 기반 디자인을 적용했다.
홈, 검색, 주제별 목록, 읽기, 비교, Docker, 책갈피와 설정은 같은 셸을 사용한다.
문서 265개와 Docker 스택 21개의 실제 데이터는 빌드 훅으로 생성한다.
원격 색인 본문은 분류 화면의 안내 영역에 보존하고, 교체한 홈과 CS 색인 원문은
`documentation-hub-maintenance-before-design.txt` 및
`cs-reference-learning-paths-before-design.txt`에 보존했다.

빌드가 참조하던 누락 이미지와 아직 없는 문서는 미포함·준비 중으로 표시했다.
기존 목차 링크에는 앵커를 보완했다. Markdown 검증기가 코드 블록 안의
언어 표기를 닫는 구분자로 오인하던 오류도 수정하고 회귀 검사를 추가했다.

배포 게이트는 strict MkDocs 빌드, 전체 문서 링크 검사, 데이터 생성 테스트,
Rust 회귀 테스트와 Chromium 탐색 검사를 실행한다.
원격 main은 전체 본문 도표·서식 검사를 배포 게이트로 실행하지 않았다.
별도로 실행한 전체 감사에서 기존 도표 구문과 Markdown 서식 오류를 확인했으며,
이번 디자인 배포가 모든 기존 문서 도표의 정상 렌더링을 보증하지 않는다.
전체 본문을 로컬의 다른 개정판으로 덮어쓰지 않았다.

공개 AI 구성에는 GitHub 공개 변수만 사용한다. 외부 AI 서버의 실제 인증과
응답 성공은 이번 브라우저 검사의 범위에 포함하지 않는다.

## 로컬 검증

- strict MkDocs 빌드 및 정적 자산 복사 통과
- Node/Chromium 테스트 43개 통과, 건너뛰기 0
- 데이터 생성 테스트 6개 통과
- Rust 테스트 18개 통과
- 문서 265개, 링크 1,203개 검사 통과

원격 Actions 결과와 배포 커밋은 PR 및 build-info.json에서 확인한다.

빠른 검색 대화상자의 지연된 close 이벤트가 다음 입력의 포커스를 빼앗는
오류를 Chromium으로 재현하고 수정했다. 닫기 직후 홈 검색 입력으로 이동한
경우 그 포커스를 유지하며, 추가 회귀 테스트는 수정 전 실패·수정 후 통과했다.
