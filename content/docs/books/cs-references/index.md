# cs-references

> **대상과 범위:** 한국어·영어 CS 참고 문서를 찾는 독자를 정식 인덱스로 안내하는 링크 페이지입니다. 문서 내용이나 최신 버전을 직접 보증하지 않습니다.

`cs-references` 인덱스는 아래 페이지에서 언어와 카테고리로 필터링할 수 있습니다.

- [CS References (EN/KR) 인덱스 바로가기](../cs-reference/index.md)

**완료 증거:** 게시된 사이트에서 링크가 HTTP 성공 상태로 열리고 필터가 두 언어의 문서를 표시해야 합니다. 링크가 실패하면 상대 경로와 생성된 라우트를 확인한 뒤 재시도하고, 해결 전에는 이 안내를 유효한 진입점으로 표시하지 않습니다.
