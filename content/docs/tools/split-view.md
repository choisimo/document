# Split View (화면 분할)


## 기능 상태와 수용 기준

이 페이지는 Split View의 사용자 동작 명세입니다. 실제 제공 여부와 기본 레이아웃, 저장 방식, 아이콘 위치와 단축키는 배포된 프런트엔드 빌드와 브라우저에서 확인해야 하며 이 문서만으로 구현 완료를 판정하지 않습니다.

- **환경 전제**: 데스크톱 키보드 사용을 중심으로 하며 브라우저, 운영체제, 입력기와 접근성 도구가 같은 단축키를 선점할 수 있습니다. 모바일과 좁은 화면에는 대체 탐색이 필요합니다.
- **상태 계약**: 패널별 검색어, 선택 문서, 활성 패널과 레이아웃의 저장 범위, 만료와 초기화 동작을 명시합니다. 민감한 검색어나 문서 위치를 영구 저장하지 않습니다.
- **실패 처리**: 문서 로드 실패, 검색 결과 없음, 세션 복원 실패와 존재하지 않는 문서에는 패널별 오류와 재시도 또는 초기화 동작을 제공합니다.
- **수용 기준**: 1x1, 1x2, 2x1, 2x2 전환, 포커스 순서, 키보드만으로 이동과 닫기, 화면 읽기 레이블, 새로고침 후 합의된 상태, 모바일 fallback을 시험합니다.

Tmux 스타일의 멀티 세션 화면 분할 기능을 사용하여 여러 문서를 동시에 탐색할 수 있습니다.

---

## 기능 개요

- **2x2 그리드 레이아웃**: 최대 4개의 독립적인 세션
- **세션별 검색**: 각 패널에서 독립적으로 검색 수행
- **문서 로딩**: 검색 결과를 클릭하여 해당 세션에 문서 표시
- **키보드 단축키**: 효율적인 탐색 지원

---

## 사용 방법

### 분할 뷰 열기

우측 하단의 **격자 아이콘** 버튼을 클릭하거나 `Ctrl+\` 를 누르세요.

### 레이아웃 선택

상단 툴바의 드롭다운에서 원하는 레이아웃을 선택하세요:

| 레이아웃 | 설명 |
|----------|------|
| 1×1 | 단일 패널 |
| 1×2 | 가로 2분할 |
| 2×1 | 세로 2분할 |
| 2×2 | 4분할 그리드 (기본값) |

### 세션 사용

1. 패널을 클릭하여 **활성화** (파란색 테두리로 표시)
2. 검색창에 **키워드 입력**
3. 검색 결과를 **클릭**하여 문서 로드
4. 다른 패널로 이동하여 같은 과정 반복

---

## 키보드 단축키

| 단축키 | 동작 |
|--------|------|
| `Ctrl+\` | 분할 뷰 토글 |
| `ESC` | 분할 뷰 닫기 |
| `Ctrl+/` | 현재 세션 검색창 포커스 |
| `Ctrl+↑/↓/←/→` | 패널 간 이동 |
| `Ctrl+Shift+1~4` | 특정 세션 직접 선택 |

---

## 활용 예시

### 비교 분석

- **왼쪽 패널**: Docker 설치 가이드
- **오른쪽 패널**: Docker 명령어 레퍼런스

### 관련 문서 탐색

- **상단**: SSH 보안 설정
- **하단**: VPN 구성 가이드

### 문제 해결

- **패널 1**: 에러 메시지 관련 문서
- **패널 2**: 해결 방법 문서
- **패널 3**: 설정 파일 예시
- **패널 4**: 관련 명령어

## 팁

!!! tip "효율적인 사용"
    - 자주 참조하는 문서는 한 패널에 고정해두세요
    - 검색어를 다르게 하여 다양한 관점에서 문서를 탐색하세요
    - `Ctrl+Arrow` 키로 빠르게 패널 간 전환하세요

!!! info "상태 저장"
    상태 저장 기능이 배포 버전에 구현되어 있고 사용자가 허용한 경우에만 마지막 레이아웃을 저장합니다. 저장 위치, 만료와 초기화 방법을 UI에 표시합니다.
