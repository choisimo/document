# 문서 사이트 개인정보와 공개 경계

이 페이지는 현재 사이트 코드에서 확인한 저장·전송 동작을 설명한다. 외부 호스팅·프록시·AI 서비스의 로그 보존 정책은 이 저장소만으로 확인할 수 없다.

## 읽기 기록은 어디에 남는가

| 정보 | 현재 사이트 셸의 저장 위치 | 지우기·보존 범위 |
| --- | --- | --- |
| 책갈피, 설정, 기본 창 배치 | 브라우저 localStorage | 탭을 닫아도 남을 수 있음 |
| 최근 문서, 열린 세션·패널, 활성 세션, 화면 상태 | 현재 탭 sessionStorage | 새로고침에서 복원. 탭 복제·브라우저 세션 복원에 영향받음 |
| 검색어·현재 탐색 화면 | URL의 hash와 탭 화면 상태 | 공유 URL·브라우저 방문 기록에도 남을 수 있음 |
| 로드된 문서와 검색 색인 | 페이지 메모리와 브라우저 캐시 | 브라우저 정책에 따라 보존 |
| AI 질문과 현재 문서 발췌 | 전송 시 설정된 외부 서비스 | 외부 서비스 정책 별도 확인 |

설정의 읽기 데이터 초기화는 책갈피, 창 배치와 이 탭의 읽기 기록을 지운다. 테마 같은 모든 설정이나 다른 탭의 독립된 sessionStorage까지 지우는 동작은 아니다. 브라우저가 저장소 접근을 거부하면 화면은 메모리 상태로 동작할 수 있고 영속 저장·삭제 성공을 보장할 수 없다.

기존 [Split View 문서](../split-view.md)의 `splitview-*` 저장 키와 현재 사이트 셸의 `ndhub.v1.*` 키는 별도 구현이다. 현재 로드되는 스크립트는 MkDocs 설정과 Network 탭에서 확인한다.

## 문서 도우미 전송

현재 도우미는 질문 전송 시 현재 문서의 제목, 정식 URL, 본문 텍스트 앞부분을 포함한다. 코드의 발췌 상한은 JavaScript 문자열 길이 기준 12,000이다. 질문이 일반적인 내용이어도 현재 문서의 발췌가 함께 갈 수 있다.

Open Notebook이 활성화되면 같은 사용자 메시지를 검색 질의로 보내므로 질문뿐 아니라 첨부된 문서 문맥도 검색 서버에 전달될 수 있다. 반환된 검색 문맥은 AI API에도 전달된다. 질문 입력에는 자격증명이나 비공개 문서를 붙여 넣지 않는다. 도우미 닫기나 요청 취소는 이미 외부에 전달된 내용을 삭제하는 요청이 아니다.

본문의 수식·다이어그램을 표시할 때 외부 CDN에서 렌더러를 불러오는 경로도 있다. “검색이 로컬에서 실행된다”는 이유만으로 외부 요청이 전혀 없다고 설명하지 않는다.

## 문서 폴더 밖의 자료도 공개될 수 있다

현재 extra 동기화 입력에는 자동화 스크립트, Docker·설정 파일, rendered, archive, prompts, notes, 일부 예제 코드가 들어 있다. 검색 메뉴에 없거나 Git이 무시하는 파일도 동기화 대상 디렉터리에 있으면 정적 파일로 복사될 수 있다.

스크립트의 `.env`·일부 확장자 제외 규칙은 파일 내용의 비밀정보 검사가 아니다. Markdown, YAML, 셸, JSON 안의 값과 파일명도 검토해야 한다. 공개 예시로 바꾼 문서와 원본의 안전성은 각각 판정한다. 새 안내문이 기존 raw 파일을 자동으로 정리하지 않는다.

브라우저 설정 파일의 모든 `PUBLIC_*` 값과 요청 헤더는 방문자가 읽을 수 있다. 비밀 provider key는 공개 JavaScript에 넣지 않는다. 공개 브라우저용 자격증명을 쓰는 경우에도 실제 허용 범위·만료·쿼터는 서버가 강제해야 한다.

## 공개 전 확인

실제 산출물에서 민감한 값, 개인 식별자, 비공개 주소, 로그·백업·키·상태 파일을 확인한다. 예시는 `docs.example.com`, `<SERVICE>` 같은 공개 자리표시자를 사용한다. 문제가 발견되면 [배포 런북](publishing-runbook.md)의 노출 대응으로 연결한다.

근거: `content/docs/javascripts/hub-app.js`의 `SESSION_KEYS`, `storageFor`, `sendAssistant`, `reset-data-confirm`, `loadScript`; `content/docs/javascripts/ai-client.js`의 `queryKnowledgeBase`, `sendMessage`; `src/automation/site/sync-extra-assets.sh`; `src/qa/split-view-privacy.test.js`는 별도 Split View 저장 경계를 검사한다.
