# 편집 거리의 상태와 점화식

Levenshtein 거리는 한 문자열을 다른 문자열로 바꾸는 삽입·삭제·교체의 최소 비용이다. 여기서는 각 편집 비용을 1, 같은 문자를 유지하는 비용을 0으로 둔다. 문자 위치 교환을 허용하는 변형은 다른 문제다.

## 상태와 초기 조건

`dp[i][j]`를 첫 문자열의 길이 i 접두사를 두 번째 문자열의 길이 j 접두사로 바꾸는 최소 비용으로 정의한다.

```text
dp[0][j] = j
dp[i][0] = i

dp[i][j] = min(
    dp[i - 1][j] + 1,                       삭제
    dp[i][j - 1] + 1,                       삽입
    dp[i - 1][j - 1] + (x[i - 1] != y[j - 1]) 교체 또는 유지
)
```

문자가 다르다고 반드시 그 자리에서 교체해야 하는 것은 아니다. 교체는 세 후보 중 하나다. 삽입·삭제를 포함한 이전 상태의 최적 비용과 비교해야 한다.

## 작은 예시

`cat`에서 `cut`으로 가는 단위 비용은 1이다. 가운데 글자를 교체하면 된다. 빈 문자열에서 `cat`은 삽입 3번이므로 3이며 `cat`에서 빈 문자열도 삭제 3번이다.

검증할 때에는 같은 문자열, 빈 문자열, 한 글자, 길이가 크게 다른 문자열과 여러 최적 경로가 있는 입력을 포함한다. 작은 입력에서 실제 편집 경로를 따라 비용을 더해 테이블 결과와 맞는지 확인한다.

## 비교 단위와 공간

byte, Unicode code point, grapheme cluster 중 무엇을 문자로 세는지 정한다. 조합형·완성형이나 대소문자 정규화 여부를 바꾸면 같은 화면의 문자열도 다른 입력이 될 수 있다.

길이 N·M의 전체 테이블은 시간·공간 `O(NM)`이다. 거리 값만 필요하면 직전 행의 의존성으로 공간을 줄일 수 있지만 실제 편집 경로 복원에는 추가 정보·다른 복원 절차가 필요하다. 가중치가 비대칭인 변형에서는 문자열을 바꾸어 놓는 최적화도 같은 의미인지 확인한다.
