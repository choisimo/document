# 문장 표현과 코사인 유사도

유사도는 문장을 어떻게 벡터로 표현하고 어떤 거리·점수로 비교하는지에 따라 달라진다. 높은 점수가 곧 사실 일치나 같은 의도를 보증하지는 않는다. 보관된 학습 주제를 독립적인 예시로 정리했으며 원문 HTML·코퍼스·모델 결과를 재배포하지 않는다.

## 표현과 비교를 나눈다

| 표현 | 보존하는 신호 | 검증할 한계 |
| --- | --- | --- |
| Bag of Words | 선택한 단어·토큰의 등장 | 순서·문맥·미등록 단어 |
| TF-IDF | 문서 내 빈도와 코퍼스 전체 빈도의 관계 | 코퍼스·tokenizer 변경에 따른 값 변화 |
| 학습된 임베딩 | 모델이 학습한 벡터 표현 | 모델 버전·언어·domain·입력 길이·정규화 |

다른 모델이나 다른 전처리로 만든 벡터를 같은 공간의 값처럼 섞지 않는다. 검색 문서와 질의가 호환되는 encoder·전처리·차원·거리 함수를 사용하는지 확인한다.

## 코사인 유사도의 작은 예시

0이 아닌 두 벡터의 코사인 유사도는 내적을 두 벡터 길이의 곱으로 나눈 값이다.

```text
cosine(u, v) = dot(u, v) / (norm(u) * norm(v))

u = (1, 0)
v = (1, 0)   → 1
w = (0, 1)   → 0
z = (-1, 0)  → -1
```

이 값은 방향의 관계다. 벡터 길이 차이를 그대로 거리로 반영하는 Euclidean distance와 해석이 다르다. 0 벡터에서는 분모가 0이므로 거부·대체 등 명시적 정책이 필요하다. 점수 0을 “아무 의미 관계도 없음”으로 일반화하지 않는다.

## 실험 구성

같은 의미의 다른 표현, 핵심 단어만 같은 다른 뜻, 부정·시간·수량이 달라진 문장, 무관한 문장을 별도로 만든다. 개인정보나 수집 권한이 불명확한 문서를 평가 코퍼스로 사용하지 않는다.

전처리·모델 revision·비교 함수·평가 문장과 기대 판정을 기록한다. 실제 점수와 순위, 실패한 문장쌍을 남긴다. 임계값은 작은 예시 몇 개의 점수만으로 운영 전체에 고정하지 않는다.

벡터 생성 시간, 검색 시간, ranking 품질을 분리한다. 캐시나 병렬화를 추가하면 같은 입력의 결과 일치와 메모리·지연을 측정한다. 특정 비율의 속도 향상은 측정 없이 주장하지 않는다.
