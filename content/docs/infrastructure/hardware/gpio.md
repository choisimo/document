# Raspberry Pi GPIO 연결 검토

보관 자료에는 여러 보드와 주변 장치의 개념 연결도가 섞여 있다. 논리 그림은 실제 커넥터 방향이나 핀 배치를 대신하지 않는다. 보드 revision과 주변 장치의 공식 pinout·datasheet를 확인한 뒤 배선한다.

## 통전 전에 확인할 항목

| 항목 | 확인할 이유 |
| --- | --- |
| 물리 핀 번호와 BCM GPIO 번호 | 같은 숫자가 같은 핀을 뜻하지 않음 |
| 보드·주변 장치 전압 | 일반 GPIO 신호는 3.3V 논리. 5V 신호를 직접 입력하지 않음 |
| LED와 직렬 저항 | 공급 전압·순방향 전압·목표 전류로 정해야 함 |
| 부하 전류·전원 | 장치 구동 전류를 GPIO가 직접 공급할 수 있다고 가정하지 않음 |
| 커넥터 규격·방향 | 디스플레이·카메라 케이블의 모델별 차이 |
| 접지·신호 기준 | 장치 간 신호 기준과 전원 회로를 datasheet로 확인 |

전원을 분리하고 배선한 뒤, 다른 사람이 확인할 수 있도록 보드 방향·핀 이름·장치 모델을 기록한다. 개념도에 “저항”이라고만 적혀 있으면 특정 저항값이 검증됐다는 뜻이 아니다.

## 최소 기능 확인

처음에는 승인된 주변 장치 하나로 입력 또는 출력 한 가지를 시험한다. 선택한 라이브러리가 보드·OS·핀 번호 체계를 지원하는지 확인하고 부팅 시 기본 상태와 종료 후 상태를 정한다. 이전 보드용 코드의 번호와 드라이버를 그대로 재사용하지 않는다.

반응이 없을 때에는 전원·배선·핀 번호·기능 설정·프로그램 순으로 나눠 확인한다. 회로를 반복해서 바꾸기 전에 전원을 끄고, 발열이나 예상하지 못한 전압이 있으면 중단한다.

이 문서는 보관 도표의 실제 핀 연결을 재게시하지 않으며 조립 완료를 주장하지 않는다. 완료 증거는 검증한 회로, 적용한 도구 버전과 제한된 기능 시험이다.
