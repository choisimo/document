`reviewed`는 해당 날짜에 링크를 참고했다는 뜻이며 현재 접근 가능성, 호환성 또는 구현 성공을 보장하지 않습니다. `main`, `latest`, raw GitHub 링크는 변경될 수 있으므로 실제 결정에는 release/tag 또는 commit SHA, 제품 버전, 확인 날짜와 적용한 결론을 함께 기록합니다.
