전체 구조를 먼저 파악하고, 파트를 내려가며, 문제 단위로 기억을 고정합니다. Spacing, retrieval, interleaving을 포함한 인지과학 기반 학습 흐름으로 구성했습니다.

Memory Loop

1) Chunking

10개 파트로 분해해 인지 부하를 줄이고, 파트별 핵심 패턴만 먼저 기억합니다.

2) Retrieval

해설을 보기 전에 "핵심 알고리즘"과 "아키텍트 관점"을 떠올려 회상 연습합니다.

3) Spacing

오늘 학습 후 D+1, D+3, D+7에 다시 회상하도록 주기적 복습 루프를 적용합니다.

4) Interleaving

인접 파트를 섞어 훈련해 패턴 구분 능력을 강화합니다 (예: 2, 3, 2, 4).
