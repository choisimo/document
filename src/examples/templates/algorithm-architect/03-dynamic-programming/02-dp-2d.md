# 2차원 DP (2D Dynamic Programming - 격자형)

## 개요

| 항목 | 설명 |
|------|------|
| **Use Case** | 격자 경로, LCS, 편집 거리 |
| **Components** | 2D DP Table |
| **Constraint** | 2차원 상태 관리 |
| **시간 복잡도** | N×M states와 constant transition을 가정하면 O(NM) |

---

## 적용 범위와 검증 기준

- **범위:** `N×M` states 각각을 constant-time transition으로 계산할 때 time이 `O(NM)`입니다. LCS·edit distance·grid 문제는 state와 transition이 서로 다릅니다.
- **공간 전제:** 기본 table은 `O(NM)` memory이며 dependency가 인접 row/column에 제한될 때만 rolling array로 줄일 수 있습니다.
- **실패 조건:** first row/column initialization, obstacle·unreachable sentinel, update order, empty dimension과 numeric overflow를 포함합니다.
- **완료 증거:** 작은 grid/string을 exhaustive/reference 결과와 비교하고 recurrence, boundary와 space-optimized 결과의 동등성을 확인합니다.

## 기본 템플릿 (격자 최소 경로)

```python
# [2D DP 템플릿: 아키텍트 버전]
# Use Case: 격자 경로, LCS, 편집 거리
# Components: 2D DP Table
# Constraint: 2차원 상태 관리

def dp_2d_grid(grid):
    # 1. 초기화 (Initialization Layer)
    rows, cols = len(grid), len(grid[0])
    dp = [[0] * cols for _ in range(rows)]
    
    # 2. 베이스 케이스 (Base Case)
    dp[0][0] = grid[0][0]
    
    # 첫 행 초기화
    for j in range(1, cols):
        dp[0][j] = dp[0][j-1] + grid[0][j]
    
    # 첫 열 초기화
    for i in range(1, rows):
        dp[i][0] = dp[i-1][0] + grid[i][0]
    
    # 3. 2중 루프 (Double Loop)
    for i in range(1, rows):
        for j in range(1, cols):
            # 4. 점화식 (Recurrence)
            #    - 위에서 오거나 왼쪽에서 오거나
            dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
    
    return dp[rows-1][cols-1]
```

## 예제: 최장 공통 부분 수열 (LCS)

```python
# [예제: 최장 공통 부분 수열 (LCS)]
def lcs(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    
    return dp[m][n]
```
