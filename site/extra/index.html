    Algorithm Simulator¶

    실시간으로 알고리즘과 자료구조를 시각화하고 학습할 수 있는 인터랙티브 시뮬레이터입니다.

    • Binary Search Tree (BST) - 삽입, 삭제, 탐색 시각화
    • Hash Table - Linear Probing 충돌 해결
    • Sorting Algorithms - Quick Sort, Merge Sort, Heap Sort
    • Heap - Max/Min Heap 연산
